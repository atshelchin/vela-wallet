# Rebuild-readiness gate (US5) — first run

**Date**: 2026-07-31 · **Method**: a fresh agent with Penpot MCP access and NO repository access,
asked to specify Home, Send end-to-end, and an ERC-20 approval for a non-RN rebuild, then to report
every gap. 68 tool calls, 13 pages read, four PNG exports.

## Verdict

> **System layer: accept.** "Tokens (147, both modes), 62 library components with
> tier/description/use-when/don't/code-path/reuse-sites, the PICK·OBEY·EXTEND recipe, the
> resilience/motion/a11y patterns, and the IA topology are all genuinely implementation-ready and
> better than most hand-written design systems. I could build the component layer from this file
> alone."
>
> **Screen layer: reject.** Send and the ERC-20 approval are specifiable. **Home is not**: "its
> balance is masked in every canon board, its Assets tab is empty, its Connections tab is empty, its
> two degraded states are the same board twice, and the whole thing is rendered in the mode the
> contract says is not the baseline."

That split is the useful result. The part built this week passed; the part inherited from the
capture sweeps did not.

## NOT fixed — needs the running app

The gate's minimum fix list ends with things no pipeline run can do, because the pixels do not exist:

1. **Recapture Home in light mode with the balance visible** and a populated Assets tab. Every Home
   board was captured with hide-balance ON, so the wallet's central number has no depiction.
2. **Recapture `S/home/rpc-trouble` with the banner present.** It and `S/home/rate-limited` are
   currently pixel-identical (143 shapes each, zero differences beyond board position) and neither
   contains an `RpcTroubleBanner` — the file collapses the exact distinction page 09 calls "the one
   most often collapsed".
3. **Fix the dropped text runs** on the signing boards: `erc-20-approve-unlimited` renders
   "You're letting … USDC" — **the word ALL is missing**, on the scenario where that word IS the
   risk. Cause is the inline-fragment truncation in `70-board-from-dom.js`; the shape NAME still
   carries the full string, which is how the gate caught it.
4. **`S/home/assets` has no assets, `S/home/connections` has no connection, `S/send/details` is
   blank** — all captured in empty states.
5. Fixture data is the parallel test space (`Parallel One/Two/Three`), which page 10 declares
   excluded from the gate; canon screens are built on it.

## Standing false-confidence risks the gate raised

- `"generated 1:1 from the live rendered DOM"` is stamped on every board and is **not** 1:1 for
  text (see #3). Check: any text shape whose `name` is longer than its `characters` lost a run.
- Page 01's lede claims "all of it is drawn from the same tokens the app runs on" while **4 of its
  181 shapes** carry a token binding. The page that states "tokens only, never a literal" violates
  it 177 times.
- Typography is exported under the key `inter` while being Plus Jakarta Sans — a live landmine for
  any stack whose `inter` key loads Inter.
- The changelog spans one day; there is no in-file signal of drift since.
