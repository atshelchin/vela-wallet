# Contract: Design-Token Pipeline

**Consumer**: every component/page in `app-web/vela-wallet`.
**Producer**: `app-web/vela-wallet/scripts/gen-tokens.mjs` reading `docs/design-tokens.json`.

## Emission rules

1. **Naming**: DTCG path → CSS variable: dots become dashes, set name dropped,
   `--` prefix. `color.bg.base` → `--color-bg-base`; `space.2xl` → `--space-2xl`;
   `motion.duration.fast` → `--motion-duration-fast`.
2. **Units**: `spacing`/`sizing`/`borderRadius`/`fontSizes`/`borderWidth`/
   `letterSpacing` values are px numbers in the export → emit with `px`.
   `radius.full` (9999) → `9999px`. `opacity`/`number` (leading, scales,
   spring params) → unitless. `motion.duration.*` / `motion.sheet.*` /
   `motion.entrance.*` → `ms`. `fontWeights` → unitless. `fontFamilies` →
   quoted family list joined with fallbacks (see rule 5). `shadow` →
   `x y blur spread color` CSS shorthand.
3. **Modes**: dark is the base — `color-dark` values in `:root`. Light emitted
   under BOTH `@media (prefers-color-scheme: light)` (with `:root:not([data-theme='dark'])`
   guard) and `:root[data-theme='light']`; dark repeated under
   `:root[data-theme='dark']`. The attribute hooks are dormant until a theme
   setting exists but must be emitted now.
4. **`core` set** is mode-independent and emitted once in `:root`.
5. **Composite font stacks** (web additions layered on export values):
   - `--font-ui: 'Plus Jakarta Sans', 'Noto Sans SC', system-ui, sans-serif`
   - `--font-mono: 'IBM Plex Mono', ui-monospace, monospace`
6. **Web additions** (absent from export; each carries a `/* web addition */`
   comment in output): `--size-control-sm: 36px`, `--size-control-md: 44px`,
   `--size-control-lg: 52px`, `--breakpoint-desktop: 1280px` (informational;
   media queries use the literal via generated `tokens.ts` constant since CSS
   custom properties cannot parameterize `@media`).
7. **`tokens.ts` exports**: `BREAKPOINT_DESKTOP = 1280`,
   `CONTROL = { sm: 36, md: 44, lg: 52 }`, `FONT_UI`, `FONT_MONO`,
   `MOTION = { fast: 150, base: 250, slow: 400 }`, plus the raw color tables
   per mode for the contrast test.
8. **Header**: both files open with `/* GENERATED by scripts/gen-tokens.mjs — do not edit. Source: docs/design-tokens.json */`.

## Invariants (enforced by tests)

- Committed output byte-equals regeneration (drift gate).
- Light and dark sets define the identical color-path set.
- No file under `src/lib/ui/` or `src/routes/` contains a hex color, `px`
  spacing/radius literal, `box-shadow` literal, or font-family literal outside
  `var(--…)` usage — except the generated `tokens.css`/`tokens.ts` and the
  single `@media (min-width: 1280px)` breakpoint literal, which must match
  `BREAKPOINT_DESKTOP`. (The audit test whitelists SVG asset files: brand-mark
  hull colors are asset content per design-system.md §Brand.)
- The breakpoint literal appearing in CSS equals `tokens.ts`'s
  `BREAKPOINT_DESKTOP` (audit extracts and compares).
